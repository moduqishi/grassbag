## 一、五种统一页面骨架（全 App 零异类页面）

所有二级页与弹层严格归入以下五种骨架之一，保证换页后用户始终知道标题、返回键、主按钮和分组在哪：

| 骨架 | 适用页面 | 固定结构与几何规则 |
| --- | --- | --- |
| **A. 枢纽页（Hub）** | 设置首页、全部功能、手机操控主页 | 顶部搜索胶囊 → **概览卡 (`OverviewCard`)**（突出账号余额 + 引擎/主机核心状态）→ 按意图分组的卡片组（全部功能用 2 列功能磁贴 `TileGrid`） |
| **B. 详情页（Detail）** | 对话详情（工作台）、容器与引擎升级、插件详情、自动化详情、主机详情 | **`PageHero` 页头**（图形 + 两行内标题 + 一行状态 + 2–3 个等宽数字指标，随滚动收进顶栏）→ 可横滑胶囊页签 (`SegmentedPill`) → 内容卡片 |
| **C. 列表页（List）** | 自动化任务、后台任务、插件市场、技能、远程主机、敏感应用名单 | 大标题 → 胶囊筛选栏（可选）→ 统一行解剖（左 32/40 图形 + 单行主标 + 单行副标 + 右侧状态点或胶囊钮）；空列表必用设计过的 `EmptyView` |
| **D. 表单页（Form）** | 粘贴/扫码远程地址、API Key / 渠道配置、引导步骤 | 标题 + 一句话 → 分组输入 → **贴键盘底部固定主按钮**；校验错误就地展示在字段下方 |
| **E. 弹层（Sheet）** | 模型与思考深度选择、主机切换、用量明细、产物菜单、快捷权限、确认框 | 顶部拖把手 → 标题行（左标题、右关闭钮垂直居中）→ 内容 → 至多 1 个主按钮；圆角 `28dp`，内容左右边距 `20dp`，宽屏最宽 `640dp` |

## 二、视觉、几何与 OKLCH 配色体系

### 2.1 硬性几何与留白标尺（量出来，不目测）

| 维度 | 规范值 | 说明 |
| --- | --- | --- |
| **对称与同心** | 顶栏高 `44dp` · 浮层圆钮 `44dp` / 图标 `22dp` · 胶囊内圆键四周等距且与胶囊两端**同心** | 关键组件（输入舱、顶栏、叠栈）均配 Flutter 几何单元测试 |
| **边距节奏** | 4 的倍数：浮层距屏边 `12dp` · 正文左右 `16dp` · 分组间距 `24dp` · 分组标题到卡片 `8dp` | 单行高 `52dp`、两行高 `64dp`；**卡片内行间不画分割线**，靠留白和行高呼吸 |
| **圆角梯队** | 卡片 `20dp` · 弹层 `28dp` · 胶囊/圆钮 `全圆` · 小标签 `8dp` | 杜绝盒子套盒子、毛玻璃套毛玻璃 |
| **层级与字号** | 标题 `600` 字重，其余 `400–500`；次要信息靠 `textTertiary` 色阶而非无脑缩小字号 | 全部数字（耗时、Token、步数、余额）强制 `tabularFigures` 等宽数字，单位小一号用次要色 |
| **主色克制** | **一屏至多一个主色实心元素**（发送键、抽屉新对话钮或选中胶囊） | 状态色只表状态，大面积保持安静中性色 |
| **图标体系** | **Phosphor 图标集**（Regular `1.5px` 圆端描边；选中/点亮/实心停止键用同骨架 Fill） | 统一走 `AppIcons.<role>` 语义映射，禁止散写 Material `Icons.*` |

### 2.2 OKLCH 配色引擎 + 自动对比度守卫

借鉴 `dsh-Go` 的 OKLCH 推导体系，保证任何主题色下文字层级、中性底面和液态玻璃通透度完全一致：

- **默认与预设配色**（强调彩度封顶 `0.13`，页面中性色彩度 `< 0.025`，安静高级）：
  1. **苔青 / 松石（GrassBag 招牌默认）**：克制低饱和青绿，呼应 GrassBag 名称气质，中性色带极轻冷绿调，久看不发绿；
  2. **雾蓝**：DeepSeek 经典褪色蓝（`#4B67B4` / `#97B1F0`）；
  3. **黛青**、**暮紫**、**琥珀（暖米白纸/暖炭黑）**、**石墨（极致极简黑白灰）**；
  4. **自定义色相条** + **Android 12+ 跟随系统壁纸动态取色**。
- **自动对比度守卫 (`AccentGuard`)**：
  - 强调色对最不利底面（`surfaceContainerHighest`）对比度 `≥ 3:1`；强调色上的文字对比度 `≥ 4.5:1`；
  - 保持色相和彩度不变，仅沿 OKLCH 明度 `L` 二分 24 步寻最近达标值；
  - **绝不随主题染色的固定语义色**：成功/警告/错误状态色、Diff 红绿、代码高亮角色色、终端 ANSI 色与图表分类色。

## 三、`liquid_glass_widgets` 液态玻璃专属设计准则

把 `dsh-Go` 的传统 `BackdropFilter` 升级为 **`liquid_glass_widgets`** 后，必须遵守以下视觉与性能边界，做到“惊艳且 120Hz 丝滑”：

1. **单屏唯一采样域**：`HomeShell` 外层包裹唯一 `GlassBackdropScope`，顶栏胶囊、底部输入舱、Dock Stack 和悬浮审批卡共享一次背景捕获，GPU 帧耗时减半。
2. **仅用于「浮层交互壳」（绝不套玻璃、绝不进滚动列表）**：
   - ✅ **使用液态玻璃**：悬浮顶栏（`[≡]`、`[标题·工作台▾]`、`[模型]` 三个等高 `44dp` 胶囊）、底部悬浮输入舱、输入舱上方 Dock Stack 智能叠放卡、悬浮审批/提问接管卡、抽屉底部 `IdentityBar`、底部弹层顶部把手表头、未装桥引导横幅。
   - ❌ **严禁使用折射玻璃**：`ChatList` 内的每一条用户/助手气泡、工具折叠卡、代码块、Diff 卡、设置分组卡片、文件树行、终端画布、**以及隐蔽官方 WebUI 逃生舱页**（防 Android `SurfaceView` 采样黑块）。
3. **三档自适应画质 (`GlassQualityTier`)**：
   - `Liquid`（Android 10+ Impeller Vulkan 默认）：完整折射 + 边缘高光 + 极克制微色散；
   - `Frosted`（OpenGL ES 降级机 / 中低端 GPU 自动档）：轻量低采样磨砂，无卡顿；
   - `Solid`（省电模式 / 高对比度 / 关闭动画）：零采样实色半透明边框，文字对比度最高。
4. **首帧零抖动**：在 `main()` 启动阶段异步执行 `LiquidGlassWidgets.initialize()` 预热着色器字节码；二级页推入动画期间对底层已覆盖页面拍静态快照（Recede Snapshot），避免推入动画每帧重算底层玻璃折射。

## 四、重点借鉴的 5 个顶级移动端微交互

### 4.1 输入舱上方的「智能叠放状态栈（Dock Stack）」
- 当 **运行思考条（带实时速度/目标摘要）**、**待办条（`3/7 正在跑测试`）**、**长期目标条**、**权限放宽提示胶囊（「自动允许中 ⓧ」）** 同时出现时，**绝不占掉三四行屏幕**！
- **两张以上自动叠成一摞**（类 iOS Smart Stack）：当前最底那张在前占一行，后面最多露出 2 张逐级缩小 5% 的玻璃顶边；
- **上下轻滑跟手切换卡片**（带轻触觉反馈），轻点整摞 340ms 平滑展开，展开态右上角提供「收起 ˅」；叠放偏好本地记忆。

### 4.2 抽屉底部极简「身份栏（IdentityBar）」+ 就近设置
- **抽屉顶部**：品牌标识 + 醒目主色「新对话」胶囊（抽屉里唯一主色）→ 搜索与筛选胶囊；对话按「今天 / 昨天 / 本周 / 更早」分组，运行中会话尾部带呼吸小点，待确认会话带高亮标签。
- **抽屉底部身份栏**：左侧主机图标 + 「本机 · 运行中」/「公司 Mac · gbridge」（点开弹主机切换 & 管理远程主机），右侧仅放两枚等大圆钮：**「全部功能」** 与 **「设置」**（长按设置直接弹出设置搜索！）。
- **就近设置（减少跳转）**：当前对话的**权限预设**、**计划模式开关**、**手机操控确认档位**直接放在输入舱 `+` 面板内，1 下即改；开启免确认后自动在 Dock Stack 挂出可一键关闭的胶囊。
- **清晰分工**：「设置」管“以后怎么样”（6 大意图分组 + 中英同义词搜索 + 高亮跳转定位），「全部功能」管“现在去做”（2 列功能磁贴网格）。

### 4.3 聊天空状态与流式输出体验
- **空状态**：居中偏上柔和品牌图形 + 时段问候 + 一行当前工作区选择胶囊（「在 `my-project` 中 ⌄」）+ 2×2 安静建议胶囊；连不上时只留 1 枚主按钮「重新连接」。
- **流式 Markdown 渲染管线（吸收 `rendering.md` 精华）**：
  1. `normalizeMath`：严格区分 `$5 and $10` 价格与 `$x^2$` 公式；流式未闭合的 `$$` 先显示源码防止半截矩阵反复跳动；行内 KaTeX 强制 `textStyle` 不撑裂行距，成块公式超宽横向滚动。
  2. `repairStreamingMarkdown`：仅修补未闭合尾部（`**`/`*`/`~~`/`` ` ``/半截链接提前按最终样式呈现，隐藏半截 HTML 标签与尚未写完语言名的代码块围栏），表格等分隔行完整后再出现。
  3. **代码、Diff 与图表**：56+ 语言高亮 + 复制 + 自动换行开关；```` ```diff ```` 整行红绿着色；GitHub 5 种 Alert 提示块与 `<details>` 折叠；工作区相对路径图片原生加载并缓存宽高防回滚跳动；**Mermaid 代码块默认显示源码 + 点击「预览」弹全屏离线渲染页**（内置 `mermaid.min.js` 到 assets，无网也能画！）。
  4. **流式跟随（Glide）**：输出新字时列表平滑滑移跟随，手指一上翻或按住立刻交还控制权；单轮正常结束后自动把思考与工具步骤折叠成一行「已完成 · N 次工具调用 · Xs」，最终正文留在外层。

### 4.4 四档横屏与平板自适应（含横屏手机防踩坑）
- **关键规则（来自 `page-design.md §7`）**：
  - 手机竖屏（`宽 < 600`）：单列 + 左抽屉 + 底部双档工作台；
  - **手机横屏（`高 < 480`，不管多宽！）**：**强制保持单列居中阅读列**（阅读列 `720dp`，悬浮输入舱 `696dp`），绝不上两栏把聊天挤成一条缝！同时用 `MirroredSideInsets` 对称镜像左右挖孔安全区；键盘弹起时自动隐去顶栏和 Dock Stack；
  - 折叠屏/小平板（`宽 600–840, 高 ≥ 480`）：单列居中 + 加宽双档底部工作台（最宽 `744dp`）；
  - 平板大屏（`宽 ≥ 840, 高 ≥ 480`）：左导轨/侧栏 + 居中聊天列 + 右侧常驻工作台（`360–420dp`）。

### 4.5 动效双档哲学（标准档 + 灵动档） & 文案纪律
- **标准档**：`150–300ms` 平滑减速曲线，按压缩 `0.97`，零弹跳、零大面积闪光、零循环装饰动画；系统关闭动画时全自动归 `0`。
- **灵动档（默认开，低端/发热降级）**：仅给位移和缩放加克制弹簧回弹（不加额外模糊层），包含按压微光、发送起飞、工具运行细圆弧 `QuietArc` + 完成后一笔画对勾、数值滚动 `RollingCount`、深浅色切换柔和揭开。
- **文案与术语铁律**：短、确定、无废话（副标题 `≤ 16` 字）；界面绝不出现 `RPC`、`投影`、`rootfs`、`carrier` 等内部开发词；统一叫「对话」「本机 / 远程主机」「引擎」「思考深度」「网页版」；报错一句话说清“发生了什么 + 怎么办”，堆栈收进「详情」。

## 五、本规范对 `/gbridge/v1` 协议的反向补充

经过 UI 设计细化，反向确认 `/gbridge/v1` 需补充 2 处轻量聚合字段，让首屏和微交互零多余请求：
1. **`GET /gbridge/v1/overview`**：单次返回设置首页 `OverviewCard` 与抽屉 `IdentityBar` 所需的聚合摘要（当前主机名/运行状态/DSH 版本/`gbridge` 版本/登录账号名与余额摘要/待处理审批数）。
2. **`turn.delta` 附带轻量化运行状态字段 `activity`**：如 `{ phase: "thinking" | "tool" | "streaming", target?: "bash: npm test", tps?: 42.5, elapsedMs: 3200 }`，直接驱动 Dock Stack 的安静运行条与输出速度指示。
